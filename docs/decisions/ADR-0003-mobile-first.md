# ADR-0003: Mobile-First Dashboard

## Status

Accepted

## Context

Court Ready is designed for quick daily use and should take about five minutes. The likely primary device is a phone.

## Decision

Design the 0.1 dashboard mobile-first, then enhance to a two-column desktop layout.

## Consequences

- The first screen prioritizes greeting, progress, and next action.
- Controls must be touch-friendly.
- Dense desktop dashboards and decorative marketing layouts are out of scope.
