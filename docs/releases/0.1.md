# Release 0.1

## Features

- Today's Dashboard at `/`.
- Greeting, date, next action, and completion progress.
- Daily checklist, workout, supplements, hydration, protein, evening routine, and note.
- Local storage persistence for daily checklist completion, water, protein, and notes.
- PWA manifest, app icon, and service worker registration.

## Fixes

- Service worker registration is production-only.
- Development unregisters existing Court Ready service workers and deletes Court Ready caches.
- Production service worker skips `/_next/` assets and uses network-first navigation handling.

## Decisions

- Keep the app single-user and local-first.
- Use a static reset-day plan for the first sprint.
- Avoid backend, auth, database, and generic fitness tracking features.

## Known Issues

- PWA icon coverage uses one SVG asset.
- No automated UI regression tests yet.
